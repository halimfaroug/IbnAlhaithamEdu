# منصة مدارس بن الهيثم الخاصة — رياضيات ٢ث

منصة عربية تفاعلية (RTL) لمراجعة منهج رياضيات الصف الثاني الثانوي (السودان)، مبنية كتطبيق ويب تقدّمي (PWA) قابل للتثبيت والعمل دون إنترنت.

## المزايا
- **بنك أسئلة** — ٨٠ سؤالًا وجوابًا مع الفكرة الرياضية، موزّعة على ٨ وحدات، مع بحث وتصفية.
- **اختبر نفسك** — اختبار متعدد الخيارات بأسئلة عشوائية، اختصارات لوحة مفاتيح (١–٤ وEnter).
- **المختبر التفاعلي** — رسوم بيانية تفاعلية (الدالة الأسية، ميل المستقيم، المتتاليات) تتحرك مع تحريك القيم.
- **لوحتي** — تتبّع النقاط والإتقان لكل وحدة ورموز الإنجاز، محفوظة محليًا على الجهاز (`localStorage`).
- **PWA** — قابلة للتثبيت على الجوال وسطح المكتب، وتعمل دون اتصال بعد أول زيارة.

## البنية
- `index.html` — التطبيق كاملًا (صفحة واحدة، بدون خطوة بناء).
- `support.js` — محرك العرض الذي يشغّل الصفحة.
- `styles.css` — نظام التصميم (الألوان والخطوط والمكوّنات).
- `manifest.json` / `service-worker.js` / `icons/` — دعم PWA.
- `assets/` — شعار المدرسة.

## النشر على Vercel
لا حاجة لأي خطوة بناء — الملفات ثابتة بالكامل:
1. ادفع محتوى هذا المستودع إلى فرع `main`.
2. في Vercel: New Project ← استورد هذا المستودع ← Deploy (بدون إعدادات إضافية).

## المحتوى التعليمي
الأسئلة والوحدات مبنية على كتاب الرياضيات للصف الثاني الثانوي الصادر عن المركز القومي للمناهج والبحث التربوي — بخت الرضا، جمهورية السودان.
